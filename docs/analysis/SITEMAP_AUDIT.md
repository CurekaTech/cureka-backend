# Sitemap audit (26 Sep 2026)

`www.cureka.com/sitemap.xml` is rewritten by `next.config.ts` to the backend
(`/api/v1/public/sitemap.xml`), generated by
`cureka-backend/modules/sitemap`.

## Timeline

- Earlier on 26 Sep (index `lastmod` 2026-09-25T16:31Z): **every** URL used
  `https://cureka.techbv.in` (a host that sends `X-Robots-Tag: noindex, nofollow`).
  Google ignores cross-host sitemap URLs, so there was no usable sitemap for
  `www.cureka.com`.
- 26 Sep ~05:24 UTC: regenerated with `https://www.cureka.com` (base URL env
  `SITEMAP_BASE_URL` / `STOREFRONT_URL` changed; the generator force-rebuilds
  on base-URL change). Start date of the wrong host is unknown.

## Issues

1. **`support.xml` 404 while listed in the index.** `buildIndexEntries`
   (`modules/sitemap/services/sitemap-generator.service.ts`) adds live keys via
   `liveKeyToPublicPath`, which maps the legacy nested `support/support.xml` to
   `/sitemaps/support.xml`; the controller serves the flat `support.xml`, which
   doesn't exist. Fix: only index files the controller can serve; delete the
   stale legacy object.
2. **`https://www.cureka.com/undefined` in products** (404). A product's
   `productPageUrl` is stored as the string `"undefined"`;
   `toStorefrontPath` (`modules/sitemap/services/sitemap-url.builder.ts`)
   accepts it. Fix: reject `undefined`/`null` strings; clean the record.
3. **`/policies/about-us` 404.** `modules/sitemap/config/cms-url.map.ts`
   maps unknown slugs to `/policies/{slug}`; the page is `/about-us`. Also
   `about-cureka` → `/about` (a 308 to `/about-us`). Map both to `/about-us`.
4. **Product URLs that redirect or 404** (~1 in 120 each in the sample,
   ≈90 each extrapolated):
   - Configured `productPageUrl` keeps an old category path after
     re-categorisation → 308 (e.g. `kohinoor-shoulder-immobilizer-fa-09-small`).
   - Slugs with `˚` (`%cb%9a`) → 308 to `…-degree-…` (2 URLs).
   - Inactive/removed product still listed → 404 (e.g.
     `healthvit-jointneed-sport`).
   Fix: emit the canonical URL only; exclude non-200 products. A full crawl of
   the 10,790 product URLs would give the exact list.
